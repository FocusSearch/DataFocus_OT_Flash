# 安装 OT Flash r53

[返回首页](../README.md) · [下载与合并](DOWNLOAD.md) · [版本说明](RELEASE-r53.md)

## 1. 确认平台和资源

本次提供 **CentOS 7 x86_64** 完整离线包。Ubuntu / Kylin 的历史包不等同于 r53，本仓库当前发行也不包含 macOS 或 ARM 安装包。

沿用随包原部署指引的参考节点规格：

| 项目 | 参考值 |
| --- | --- |
| CPU | 8 vCPU，支持 SSE4.2 与 POPCNT |
| 内存 | 32 GB |
| 根分区 | 不少于 50 GB |
| 数据磁盘 | 不少于 300 GB，按业务数据量规划 |
| 安装权限 | root 执行引导，按原流程初始化专用安装用户 |

以上来自原部署指引，不是 r53 新增的最小资源压测结论。下载分卷并合并时会同时保留分卷和完整归档，请为这一步预留至少 15 GiB；解包、容器镜像、运行数据和备份还需要额外空间。

请使用专用测试服务器或隔离虚拟机。安装器会配置容器运行环境、网络、安装用户和服务，避免在已经承载其他业务的机器上直接执行。原指引默认使用的容器网络包含 `10.244.0.0/16`、`10.96.0.0/12` 和 `172.17.0.0/16`，部署前检查冲突并按原引导配置。

## 2. 下载与校验

按 [下载说明](DOWNLOAD.md) 获取四个分卷，或执行 [download-r53.sh](../scripts/download-r53.sh)。得到完整包：

```text
OT_Flash_0.1.0-test_CentOS7_X86_64-r53.tar.gz
```

完整包的 SHA-256 必须为：

```text
e045423b2744e0f28c3f46b649aa20724ea8d79686d5d96e8ed7c48b4e699abd
```

## 3. 解包并运行原安装引导

```bash
tar -xzf OT_Flash_0.1.0-test_CentOS7_X86_64-r53.tar.gz
cd OT_Flash_0.1.0-test_CentOS7_X86_64
```

先阅读完整原指引：`deploy/script/Install-guide.md`。新安装按其流程初始化每个节点的专用安装用户，再运行引导：

```bash
# 新安装：在每个节点按原指引初始化安装用户
bash deploy/script/tools/init-ssh-user.sh

# 主节点：进入原安装、升级、备份与恢复菜单
bash install-guide.sh
```

已有实例升级时使用菜单中的“升级”，保留原实例身份、授权和安装配置；不重新执行用户初始化，也不把新安装流程当作升级。正式升级前按原流程创建并核对可恢复的备份。

## 4. 完成实例授权与模型配置

新实例沿用原 AppCenter / SysMgr 授权流程：取得设备 UUID、获取对应授权文件、完成授权激活与初始化配置。外部 AI 服务、模型及 OCR 根据实际站点配置。

发行包不携带可复用的其他实例许可证、模型 token 或业务数据。默认管理员为 `admin`，初始密码为 `2020@Datafocus`；请完成原账户初始化和改密流程。访问地址按安装引导返回的站点地址使用。

## 5. 安装后核对

1. 管理员登录成功，BI 工作台和本体入口正常显示。
2. 上传自己的 CSV，确认导入完成，原读表页面可查看真实数据。
3. 上传独立测试文档，确认解析、嵌入和索引成功，再验证检索结果。
4. 根据站点权限和模型配置验证 Agent 工具调用。
5. 若测试本体发布，先核对原校验预算账户、精确发布公钥信任和治理条件。r53 的既有验收没有完成该发布闭环，不应以候选预览代替正式发布。

## 备份与恢复

沿用原备份/恢复菜单。Doris 使用原生在线快照，接入 S3 兼容存储；已有 S3 / MinIO 的连接凭据应按原受保护配置机制提供。备份包含敏感配置，按业务备份管理。恢复过程会中断服务。

## 本次实际验证

r53 已通过 CentOS 7 测试实例的完整升级和服务恢复，并完成登录、Doris 原读表及已有文档资产保留检查。没有将这一升级结果扩展成所有操作系统、所有数据库或 r53 全新机器安装的通过结论。详细范围见 [版本说明](RELEASE-r53.md)。
