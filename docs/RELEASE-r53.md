# OT Flash 0.1.0-test · r53

**测试发行候选 / Pre-release** · 构建与验收日期：2026-10-06 · 平台：CentOS 7 x86_64

## 发行目标

在原 DataFocus 页面、API、权限和业务流程上，以 Doris 承载数据底座，聚焦 Agent 的结构化数据与文档知识服务。此发行线不包含完整 ETL 产品能力和 AutoML。

## 本轮更新

### 本体与 Agent

- 吸收已核对的 mac 非 AutoML 本体增量：维护批量权限/依赖读取、发布闭包复用、完整观察轮次的根读取复用、精确修订校验缓存与 canonical JSON 优化。
- 保留现行 OAuth、来源权限和精确版本检查；不把读取缓存当作授权缓存。
- 更新 Runtime 的明确版本绑定、元数据重查和维护上下文交接。
- 修正通用 MCP 提交输入 schema 误嵌套工具描述导致的候选合同校验问题。
- 吸收共用 MCP 预览按实际持久化作用域重新核权的修补；AutoML 增量不合入此包。

### Doris 数据链

- 支持真实中文源字段，保留资源标识符与权限的原校验规则。
- 将物理 `decimalv3(p,s)` 规范化为原逻辑 `decimal(p,s)`，保留精度和小数位。
- 原生 Doris datasource 复用真实 JDBC 执行证据入口，沿用原连接身份、异常和取消语义。
- 接受 Doris 查询 ID 每段省略前导零的实际格式，保留原值，仍拒绝全零和非法 ID。

### 文档批量导入

- 修复父页面全局配置读取引起的渲染错误。
- 修复批量声明循环的重复插入，保留原事务、配额和重放语义。
- 同一分块读取中计算整文件 SHA-256，恢复时重读原始分片，不放松存储校验。
- 修复封存请求计数字段的类型：计数为数字，大整数资源编号仍为字符串。
- 完整重建并绑定实际 Worker 源码，保留普通及 V2 Worker 协议。

## 已知限制

- **正式本体发布未完成验收。** 测试实例没有原校验预算账户，PLAN 的预算预留被拒绝；发布投影的精确公钥信任也需要管理员预先配置。这些检查未被绕过。
- 发布后业务查询、完整分页和来源更新后的旧游标失效，以及融合引用、冲突处理、局部自动更新没有完成本包端到端验收。
- 未安装并逐一测试所有 JDBC 数据库、全部文档格式、每一种界面及搜索语言。
- 多语言和 BI 工作台相关未受影响证据沿用此前记录，并非 r53 再次全量回归。
- 模型及 OCR 依赖站点配置；使用外部模型网关时须确认 reasoning 字段不会被转成正文输出。
- 原 Doris 相关扫描字节硬预算兼容能力仍有边界；不能将客户端计时或推算值当作引擎的强制执行回执。
- 安装器成功后仍记录既有统计上报 server-code 配置路径告警；独立登录与基本业务检查通过。
